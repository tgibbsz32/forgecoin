# Android native RandomX hashing integration — 2026-10-29

This phase compiles the project's vendored `external/randomx` source for ARM64 using CMake/NDK and exposes a bounded `NativeRandomX.hash(key, input)` light-VM JNI test primitive. It performs one RandomX calculation and does **not** search nonces, mine blocks, communicate with any peer/pool, or submit transactions. Inputs are disposable test vectors, not wallet secrets.

Verified on Windows development machine: Gradle `:app:assembleDebug` completed successfully, producing an APK with the new native RandomX target. The combined `:app:assembleDebug :app:connectedDebugAndroidTest` run returned nonzero because the previously connected physical Samsung disappeared from ADB during testing (`Connected device with serial R3CY10B5KRL not found`). Only the x86_64 emulator remained. **No physical ARM64 RandomX hash result or vector acceptance is claimed**. The Android instrumentation test for native load, two deterministic hashes and argument rejection exists but is unexecuted on the ARM64 phone.

Important outstanding test gates: reconnect Samsung and run the instrumentation; compare the hash against published RandomX known-answer vectors (determinism alone is insufficient); measure device memory/thermal footprint; integrate FRG block-template seed/height logic and validated PoW jobs; only then implement interruptible nonce search, solo RPC or pool Stratum submission. The native FRG 25-word mnemonic, account scanning and signing are entirely separate unimplemented wallet tasks. Production controls remain disabled and independent review remains mandatory.
