ForgeCoin downloads

Obtain software only from the official repository. Check the official Releases page for future verified assets and their stated network. There is currently no approved public FRG mainnet Windows or Android wallet/miner download. Private prelaunch builds and restricted Android UI previews are not usable public mining wallets. See the component-by-component acceptance checklist.

NOT RELEASED

Windows desktop wallet

Windows Forms and Tauri sources are available. A source-only desktop build and test-chain native wallet transfers have passed, but an installer still needs independently reviewed frozen native sidecars, clean-machine wallet recovery, live solo/pool acceptance, distribution signing and hash verification. Do not install a historical private prelaunch bundle as a public wallet.

NOT RELEASED

Android wallet and CPU miner

The existing Android APK is a restricted debug UI preview with read-only battery/thermal diagnostics. It does not contain a working native FRG wallet, solo miner or pool miner. ARM64 native code, secure wallet recovery, background-service and physical handset verification are incomplete.

What is coming next

The delivery plan includes official-pool integration in Tauri alongside solo and custom-pool mining, a pool dashboard, standalone Pool Observer and a completed online blockchain explorer. The pool will charge a 1% operator fee on eligible pooled rewards; solo mining has no project-pool fee. These planned services are not downloads or live endpoints yet.

Before installing

Review the security policy, confirm file hashes, protect your recovery seed, and confirm whether you are using the development chain or a future approved mainnet release. Existing development-chain balances will not automatically migrate. Treat unreleased builds as experimental. Do not expose wallet RPC or unrestricted daemon RPC to the public internet.
