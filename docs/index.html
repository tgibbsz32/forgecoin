ForgeCoin (FRG) is building independent private digital cash through CPU-oriented RandomX proof of work, with owner-controlled wallets. The next intended expansion after launch is a redeemable Solana wFRG bridge, followed later by an FCMP++/CARROT privacy upgrade, ideally on the same blockchain.

Private money.

ForgeCoin starts with its own proof-of-work network. The roadmap builds the tools around it: a desktop wallet and miner, an official pool, public monitoring, community representation and future routes to use and exchange FRG.

MONETARY POLICY

A native fair launch

No allocated founder, team or ICO premine. Native block subsidy goes to proof-of-work miners. The primary-emission reference is 50 million FRG, followed by perpetual 0.20 FRG per-block tail emission; there is no fixed maximum supply. Release code and genesis still require independent verification.

MINING & TOOLS

Your choice of mining

Solo mining, the planned official pool with a 1% operator fee, and independent pools. Tauri brings wallet, node and mining controls together; the pool dashboard, standalone Pool Observer and online explorer complete the planned monitoring tools.

LONG-TERM DIRECTION

Build on native FRG

Develop a ten-seat native FRG representative chamber, practical trading routes and optional user-deposit-backed Solana interoperability. Governance rules need ratification; trading and bridge designs need feasibility, liquidity and security validation.

DEVELOPMENT ROADMAP

Native FRG. Solana next. FCMP++ after.

First complete the native network and mining tools. The first intended post-launch expansion is a user-backed 1:1 wFRG bridge on Solana. Later, aim to introduce FCMP++ and CARROT through an upgrade of the existing FRG chain if feasible. Native swaps, L2 settlement and possible L3 applications follow as research workstreams. All are planned, not live.

PHASE 1 / PRE-LAUNCH

Validate the native network

Resolve genesis, verify mining rewards and difficulty, complete cross-platform builds, wallet testing, security review and public infrastructure.

PHASE 2 / PLANNED

Build the official native FRG pool

Implement and test RandomX shares, durable accounting and mature native payouts, then deploy through private staging and controlled beta. Official pool policy: 1% of eligible pooled rewards; payout transaction costs are separate. The 100-worker target is unverified. Independent pools remain welcome.

PHASE 2 / PLANNED

Solo and pooled mining in Tauri

Keep local solo mining and custom pools. Add verified official-pool selection, fee disclosure and accepted-share/payout status after deployment. Solo mining has no project-pool fee. Existing miner controls do not mean the official pool is live.

PHASE 2 / PLANNED

Pool website and dashboard

Complete pool statistics, workers, shares, blocks, payout history, setup and FAQ pages with a secured backend. Show timestamped data and explicit unavailable states; no verified live pool feed is connected.

PHASE 2 / PLANNED

Standalone Pool Observer

Build a separate read-only web tool for solo-versus-pool estimates, share effort and probability charts. Test the calculations and distinguish sample inputs from live observations. Estimates never guarantee rewards.

PHASE 1 / UNFINISHED

Complete the online blockchain explorer

Finish and test the existing block/transaction explorer, including confirmations, pagination, reorgs and node outages. Complete security review, HTTPS, monitoring and rollback before publishing a verified public link.

PHASE 3 / RESEARCH

Native FRG trading

Evaluate noncustodial peer-to-peer trades, independently reviewed atomic swaps and third-party routes to USDC, ETH and SOL. No provider or liquidity is currently confirmed.

FIRST POST-LAUNCH INTEGRATION / PLANNED

Wrapped FRG on Solana

We intend to build a corresponding Solana SPL/Token-2022 token backed 1:1 by deposited native FRG, with a reviewed bridge for minting, burning, secure reserves and native redemption. This is the first adoption expansion after mainnet, not additional FRG mining or an existing bridge.

LATER L1 UPGRADE / RESEARCH

FCMP++ and CARROT

Plan full-chain membership proofs, CARROT addressing, curve-tree databases, proof validation, legacy-output compatibility, mempool transition and a dedicated stressnet. Prefer upgrading the existing FRG chain in-place by hard fork; only consider a new chain and voluntary bridge/migration if necessary.

FUTURE L1 / L2 / L3

Private finance and interoperability

Research native atomic swaps, backed privacy-shielded stable assets, TSS/MPC-secured private block-trade routing with potential basis-point fees, L2 payments and future L3 applications. Each needs additional protocols and independent audits; public-chain settlement is not inherently invisible.

Release stages: offline build and tests → isolated two-miner payout/reorg/recovery verification → private staging and load tests → independent security review → controlled beta → monitored public rollout. The official pool, dashboard and standalone Pool Observer are not live; the public explorer remains unfinished. Read the implementation and acceptance plan.

The 1% pool-operator fee is not an automatic governance-treasury allocation. Any future governance treasury, crypto bridge, privacy upgrade, L2 or L3 service requires separate engineering and authorization. No wrapped token, swap, synthetic asset or bridge exists today. The future migration plan must protect user redemption and prevent duplicate FRG supply. Read the bridge, FCMP++/CARROT and future capabilities plan.
