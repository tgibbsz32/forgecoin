# ForgeCoin documentation and project direction

**Current proposed mFRG policy (November 1, 2026):** 50,000,000 standard Solana SPL mFRG, six decimals; 5,000,000 initial presale (10%), 5,000,000 future liquidity (10%), 40,000,000 combined staking/collateral/ecosystem reserve (80%). This revises the October 28 500M plan. **Proposed flat presale price: $0.12 per mFRG; sale proceeds 90% project / 10% founders (half founder proceeds immediately, half over six months)**, and no mint, payment, sale or staking operation is authorized. Legacy 500M plans, test fixtures and implementation assumptions require migration before any deployment.

Discover Your City is a planned multiplayer real-world city/property simulation. Optional mFRG checkout for USD-priced CITY packs would require server-side finalized payment verification and exactly-once CITY credit; all mFRG receipts would go to the designated ecosystem treasury. No payment feature is live.

**Native FRG** is a separate mined asset. The native 50M primary emission reference is not a hard cap under the documented tail reward. A future FRG↔mFRG 1:1-backed bridge is only a proposal, not an active conversion or guarantee.
