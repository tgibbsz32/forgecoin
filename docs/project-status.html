Project development update · October 28, 2026

ForgeCoin network and miniFORGE: project status

ForgeCoin is developing two independent assets: native privacy-oriented CPU-mined FRG, and a separately planned Solana SPL utility token miniFORGE (mFRG). Both are in controlled development. This page distinguishes verified software progress from unlaunched production features.

Native chain · prelaunch

FRG network

Monero-derived privacy chain, RandomX CPU mining and approximately two-minute target blocks. Planned Windows wallet/miner, Android wallet/mining features, official pool, explorer and worker statistics are subject to native validation and public release gates. Do not mistake development interfaces for a launched public network.

Native chain status · Mining information

Solana · pre-deployment

miniFORGE (mFRG)

Planned fixed supply of 500,000,000 mFRG at six decimals, across nine specified allocations. The Solana mainnet mint has not yet been deployed. No live mint address, presale, staking service, swap, liquidity pool or distribution is authorized.

Development progress versus production readiness

  • Engineering: offline mint-history analysis, account reconciliation, Ed25519 attestations, challenge replay controls, ledger backup/restoration, signed checkpoints and reviewer quorum tests have been developed in GitHub.
  • Next deployment phase: finalize mainnet mint authority and treasury policies, obtain security review, simulate and test deployment, then request explicit owner approval before creating any Solana mainnet token.
  • Native FRG: validate live RandomX solo/pool acceptance, payouts, wallet restoration, network identity and mobile/desktop release packages before announcing public mining.
  • Website and applications: the site, wallet/miner interfaces, pool statistics, explorer and planned news/updates are separate development tracks; presence of an interface does not imply live functionality.

Longer-term proposals

Research proposals include FCMP++ full-chain anonymity, CARROT addressing, improved zero-knowledge privacy, Solana interoperability and future FRG-to-mFRG participation mechanisms. These may require consensus changes or hard forks. Future upgrades are proposed, not guaranteed or active.

Important availability notice

miniFORGE is not currently offered for sale. Do not send SOL, USDC or FRG to any address claiming to accept mFRG payments. mFRG is not wrapped FRG, not redeemable for native FRG at a fixed ratio, and does not inherit native FRG transaction privacy. No investment returns, exchange listing, date or price is guaranteed.
