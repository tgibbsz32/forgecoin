What has been verified in test-only native CI?

The independent native wallet received exactly 1.00000000 FRG from a test sender in a mined FAKECHAIN block and retained it after the receiving RPC process was restarted. The real C pool separately matured a test block, allocated a 1% fee and quarantined a deeply orphaned credited block. These successes do not prove a real production pool payout, public network agreement or permanent inability to spend genesis outputs.

Native wallet restart test · C pool reward/reorg test · Unfinished payout journal

Public release requirements

Independent frozen-consensus and signed genesis-spend rejection review; independently operated node comparisons; real C-pool wallet payout journal and exactly-once settlement; native Windows and Android wallet/miner tests with safe recovery and actual devices; verified explorer/HTTPS and Oracle configuration; signed, checksummed, reproducible releases; and explicit launch authorization.

ForgeCoin's separately proposed 50,000,000 mFRG Solana token, reserve-backed FRG bridge, liquidity, staking, and Discover Your City integration are future possibilities, not part of the initial native FRG release. The earlier 500M mFRG plan is superseded. No mint, sale, bridge or mFRG payments are active.
